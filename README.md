# BetterDiscordPlugins

A collection of BetterDiscord plugins maintained, adapted, or archived in this repository.

Individual plugin headers remain the authoritative source for authorship and attribution. Some plugins in this repository originate from other developers and are preserved or modified here for compatibility and personal use.

## CustomActivities

**Latest version: 2.2.0 CLEAN**

[CustomActivities](Plugins/CustomActivities/README.md) lets you create, save, manage, and switch custom Discord Rich Presence profiles directly from BetterDiscord.

Key features include:

- Multiple saved activity profiles
- Playing, Streaming, Listening, Watching, and Competing activity types
- Rich Presence details, state, and elapsed timer
- Large and small image asset keys with hover text
- Up to two external activity buttons
- Auto-start profile support
- Optional Rich Presence protection from other RPC applications
- Quick-access button next to Discord's user controls
- Responsive, high-contrast interface designed for both dark and light themes
- Duplicate installation detection to help prevent BetterDiscord from loading an outdated copy

## Installation

1. Open the folder of the plugin you want to install.
2. Download the `.plugin.js` file.
3. Place it in your BetterDiscord plugins folder.
4. Enable the plugin from **User Settings > BetterDiscord > Plugins**.

For CustomActivities, keep only one `CustomActivities.plugin.js` file in the BetterDiscord plugins directory.

## Notes

BetterDiscord plugins depend on Discord's internal client modules. Discord updates may occasionally require plugin updates.
